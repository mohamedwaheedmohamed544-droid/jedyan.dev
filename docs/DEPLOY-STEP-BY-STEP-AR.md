# نشر موقع جديان + لوحة التحكم — دليل تفصيلي بكل خطوة

هذا الدليل مكتوب لشخص لم يستخدم أدوات المبرمجين من قبل. كل ما تحتاجه: متصفح، وبريد إلكتروني.
الوقت المتوقع: **من 30 إلى 45 دقيقة** أول مرة.

المسار الكامل يتكون من أربع محطات:

```
1) GitHub      →   مكان تخزين ملفات الموقع
2) Neon        →   قاعدة البيانات (المحتوى + الطلبات + الصور)
3) Vercel أو Netlify  →   تشغيل الموقع على الإنترنت
4) الدومين jedyan.sa  →   ربط الاسم بالموقع
```

---

# المحطة 0 — تجهيز الملفات على جهازك

1. نزّل ملف `jedyan-web-cms.zip` من المحادثة.
2. اضغط عليه بزر الفأرة الأيمن → **استخراج / Extract**.
3. افتح المجلد الناتج. يجب أن ترى بداخله مجلدات وملفات مثل:
   `app` · `components` · `content` · `lib` · `public` · `styles` · `docs` · `package.json` · `README.md`
4. **مهم جدًا:** إذا وجدت مجلدًا بداخله مجلد آخر بنفس الاسم (أي `jedyan-web/jedyan-web/app`)، ادخل للمجلد الداخلي — هو المجلد الصحيح. الملفات مثل `package.json` يجب أن تكون في المستوى الأول من المجلد الذي سترفعه.

---

# المحطة 1 — رفع الملفات على GitHub (من المتصفح، بدون أوامر)

### 1‑أ) أنشئ حسابًا
1. افتح **github.com** → اضغط **Sign up**.
2. اكتب بريدك الإلكتروني → كلمة مرور → اسم مستخدم (مثلًا `pureminds-dev`) → أكمل التحقق.
3. فعّل الحساب من رسالة البريد التي ستصلك.

### 1‑ب) أنشئ مستودعًا (Repository)
1. من الزاوية العليا اضغط علامة **+** → **New repository**.
2. **Repository name:** اكتب `jedyan-web`
3. اختر **Private** (خاص) — هذا مهم لأن ملفات الموقع خاصة بالشركة.
4. **لا تفعّل** أي خيار من: Add a README / .gitignore / license.
5. اضغط **Create repository**.

### 1‑ج) ارفع الملفات
1. في الصفحة التي ظهرت اضغط الرابط: **uploading an existing file**
   (أو ادخل على تبويب **Add file → Upload files**).
2. افتح مجلد المشروع على جهازك، **حدّد كل شيء بداخله** (Ctrl+A في ويندوز / Cmd+A في ماك) ثم **اسحبه** إلى المساحة المكتوب عليها *Drag files here*.
   - يرفع GitHub المجلدات الفرعية تلقائيًا.
   - الرفع قد يستغرق 1–3 دقائق. انتظر حتى تنتهي كل الأشرطة.
3. أسفل الصفحة في خانة *Commit changes* اكتب: `Jedyan website + dashboard`
4. اضغط **Commit changes**.

### 1‑د) تأكد أن الرفع صحيح
في الصفحة الرئيسية للمستودع يجب أن ترى الملفات التالية مباشرة (وليست داخل مجلد إضافي):
`package.json` · `next.config.mjs` · `app` · `components` · `lib`
إن رأيت مجلدًا واحدًا فقط اسمه `jedyan-web`، فادخل إليه وستجد أنك رفعت مستوى زائد — احذف الملفات وأعد الرفع من داخل المجلد الصحيح.

# المحطة 2 — إنشاء قاعدة البيانات (Neon)

> لماذا؟ لأن Vercel و Netlify لا يحفظان الملفات بشكل دائم، فنحتاج مكانًا ثابتًا لتخزين المحتوى والطلبات والصور.

1. افتح **neon.tech** → **Sign up** → اختر **Continue with GitHub** (أسهل، نفس الحساب).
2. ستظهر شاشة **Create your first project**:
   - **Project name:** `jedyan`
   - **Postgres version:** اتركه كما هو
   - **Region / Cloud:** اختر **AWS – Europe (Frankfurt)** أو **AWS – Middle East (Bahrain)** إن ظهرت.
3. اضغط **Create project**.
4. ستظهر نافذة **Connection string** بها نص طويل يبدأ بـ `postgresql://`
   - اضغط زر **Copy** بجانبها.
   - **الصقها مؤقتًا في ملف Notepad** حتى نستخدمها بعد قليل.
   - شكلها هكذا:
     `postgresql://neondb_owner:XXXX@ep-cool-name-123.eu-central-1.aws.neon.tech/neondb?sslmode=require`

> إن أغلقت النافذة: من لوحة Neon اضغط **Dashboard → Connect** وستظهر لك من جديد.

# المحطة 3‑أ — النشر على Vercel (الخيار الموصى به)

### 1) أنشئ حسابًا
1. افتح **vercel.com** → **Sign Up** → **Continue with GitHub** → **Authorize Vercel**.
2. اختر **Hobby** (مجاني) عند السؤال عن نوع الاستخدام، ثم اكتب اسمك.

### 2) استورد المشروع
1. من لوحة Vercel اضغط **Add New…** (أعلى يمين) → **Project**.
2. في قائمة **Import Git Repository** ابحث عن `jedyan-web`.
   - لو لم يظهر: اضغط **Adjust GitHub App Permissions** → اختر حسابك → فعّل الوصول للمستودع → **Save**.
3. اضغط **Import** بجانب `jedyan-web`.

### 3) اضبط الإعدادات قبل النشر
في صفحة **Configure Project**:
- **Framework Preset:** يجب أن يكون **Next.js** (يُكتشف تلقائيًا — لا تغيّره).
- **Root Directory:** اتركه `./` (إلا إن كانت ملفاتك داخل مجلد، فاضغط **Edit** واختر المجلد الذي فيه `package.json`).
- **Build and Output Settings:** لا تلمسها.

ثم افتح **Environment Variables** وأضف ثلاثة متغيرات، واحدًا واحدًا (Key ثم Value ثم **Add**):

| Key | Value |
|---|---|
| `DATABASE_URL` | الصق رابط Neon الذي نسخته |
| `ADMIN_EMAIL` | `info@jedyan.sa` |
| `ADMIN_PASSWORD` | كلمة مرور قوية تختارها (احفظها) |

### 4) انشر
1. اضغط **Deploy**.
2. انتظر 2–4 دقائق حتى تظهر كلمة **Congratulations**.
3. اضغط **Continue to Dashboard** ثم **Visit** لفتح الموقع.
   - الرابط سيكون مثل: `https://jedyan-web.vercel.app`
   - أول فتحة قد تستغرق ثوانيَ إضافية لأن قاعدة البيانات تُنشأ ويُزرع المحتوى تلقائيًا.

### 5) ادخل إلى لوحة التحكم
1. افتح `https://jedyan-web.vercel.app/admin`
2. سجّل الدخول بالبريد وكلمة المرور اللذين وضعتهما في المتغيرات.
3. من القائمة الجانبية: **المستخدمون ← تغيير كلمة المرور** واكتب كلمة مرور جديدة واحفظها.

### 6) اربط الدومين jedyan.sa
1. في Vercel: **Settings → Domains → Add**.
2. اكتب `jedyan.sa` واضغط **Add**، ثم كرّر مع `www.jedyan.sa`.
3. Vercel سيعرض لك السجلات المطلوبة. ادخل إلى لوحة مزوّد الدومين (حيث اشتريت jedyan.sa) → **DNS Management** وأضف:
   - نوع `A` — الاسم `@` — القيمة `76.76.21.21`
   - نوع `CNAME` — الاسم `www` — القيمة `cname.vercel-dns.com`
4. احفظ، وانتظر من 10 دقائق إلى ساعتين حتى يتحول المؤشر في Vercel إلى **Valid Configuration** (شهادة HTTPS تُركّب تلقائيًا).
5. أخيرًا: لوحة التحكم ← **الإعدادات ← رابط الموقع** اكتب `https://jedyan.sa` ثم **حفظ التغييرات**.

# المحطة 3‑ب — النشر على Netlify (بديل)

### 1) أنشئ حسابًا
1. افتح **app.netlify.com** → **Sign up** → **GitHub** → **Authorize**.

### 2) استورد المشروع
1. اضغط **Add new site** → **Import an existing project**.
2. اختر **Deploy with GitHub** → امنح الصلاحية → اختر `jedyan-web`.

### 3) إعدادات البناء
ستظهر تلقائيًا من ملف `netlify.toml` الموجود في المشروع:
- **Build command:** `npm run build`
- **Publish directory:** `.next`
لا تغيّرها.

### 4) المتغيرات
1. في نفس الشاشة اضغط **Add environment variables** (أو بعد النشر: **Site configuration → Environment variables → Add a variable**).
2. أضف نفس الثلاثة: `DATABASE_URL` و `ADMIN_EMAIL` و `ADMIN_PASSWORD`.

### 5) انشر
1. اضغط **Deploy jedyan-web** وانتظر انتهاء البناء (تتابعه من تبويب **Deploys**).
2. افتح الرابط الظاهر (مثل `https://random-name-123.netlify.app`).
3. لتغيير الاسم: **Site configuration → Site details → Change site name**.
4. ادخل `/admin` وسجّل الدخول وغيّر كلمة المرور.

### 6) الدومين
**Domain management → Add a domain** → اكتب `jedyan.sa` → اتبع السجلات التي يعرضها Netlify عند مزوّد الدومين → ثم اكتب الرابط في لوحة التحكم ← الإعدادات ← رابط الموقع.

# المحطة 4 — اختبار نهائي (5 دقائق)

جرّب بالترتيب وتأكد من كل نقطة:

1. الصفحة الرئيسية تفتح والحركة تعمل.
2. القائمة العلوية تنقلك بين الصفحات الثماني.
3. زر **English** ينقلك إلى `/en` والاتجاه يتغير لليسار.
4. صفحة **تواصل معنا** → أكمل الأسئلة الخمسة → أرسل طلبًا تجريبيًا.
5. `/admin` ← **طلبات العملاء** → يجب أن يظهر الطلب التجريبي.
6. `/admin` ← **الصفحات والأقسام** ← الرئيسية → غيّر كلمة في عنوان أي قسم → **حفظ التغييرات** → افتح الموقع وحدّث الصفحة → يجب أن يظهر التعديل.
7. `/admin` ← **مكتبة الصور** → ارفع صورة (أقل من 4 ميجابايت).
8. افتح `https://<موقعك>/sitemap.xml` وتأكد أنه يعمل.

# حلول لأشهر المشاكل

| المشكلة | السبب والحل |
|---|---|
| **فشل البناء (Build failed)** ورسالة عن `package.json` | رفعت مجلدًا زائدًا. في Vercel: **Settings → General → Root Directory → Edit** واختر المجلد الذي فيه `package.json`، ثم **Redeploy**. |
| الموقع يفتح لكن يظهر **Application error / 500** | متغير `DATABASE_URL` ناقص أو خاطئ. راجع المتغيرات، وتأكد أن الرابط ينتهي بـ `?sslmode=require`، ثم **Redeploy**. |
| **بيانات الدخول غير صحيحة** عند فتح `/admin` | تأكد من `ADMIN_EMAIL` و`ADMIN_PASSWORD` في المتغيرات (يجب ألا يكون بها مسافات)، ثم أعد النشر وجرّب مرة أخرى. |
| التعديل لا يظهر على الموقع | اضغط «حفظ التغييرات» وانتظر ثانيتين ثم حدّث صفحة الموقع (Ctrl+F5). |
| رفع الصورة يفشل | الحجم أكبر من 4 ميجابايت — اضغط الصورة أولًا (مثلًا من squoosh.app) أو حوّلها إلى WebP. |
| الدومين لا يعمل بعد ساعة | راجع سجلات DNS عند مزوّد الدومين، واحذف أي سجل `A` قديم للجذر `@` يشير لمكان آخر. |
| نسيت كلمة المرور نهائيًا | احذف متغير `ADMIN_PASSWORD` وضع كلمة جديدة، ثم اطلب من مطوّر تشغيل: `node scripts/reset-password.mjs info@jedyan.sa "كلمة-جديدة"` مع نفس `DATABASE_URL`. |

# كيف أعدّل الموقع لاحقًا؟

- **المحتوى والتصميم والصفحات والطلبات:** من `/admin` مباشرة — لا حاجة لأي خطوة تقنية.
- **تعديل في الكود (تصميم جديد أو قسم برمجي جديد):** عدّل الملفات على GitHub (أو ارفع نسخة محدّثة)، وسيعيد Vercel/Netlify النشر تلقائيًا خلال دقيقتين.
- **نسخة احتياطية:** Neon يحتفظ بنسخ تلقائية، وتستطيع تصدير الطلبات من اللوحة كملف Excel في أي وقت.
